# Hexa Pixel Studio

A browser-based 16×16 pixel-art editor with pen, eraser, fill, color picker, undo/redo, PNG export, project save/open, and a comic-style speech bubble tool.

## Run locally

Open `index.html` in any modern browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. Your site will be available at `https://shseulu-web.github.io/hexa-pixel-studio/` after GitHub finishes publishing.
